# Solana AI Sentiment Momentum Agent 🧠📈

An autonomous AI trading agent combining NLP sentiment oracles with **Jupiter V6** high-speed swap execution on Solana.

## 🎯 Architecture
- **NLP Sentiment Engine:** Processes real-time developer and social activity to calculate momentum sentiment scores.
- **On-Chain Volume Verification:** Validates that sentiment spikes correlate with actual DEX volume on Birdeye and DexScreener.
- **Jupiter V6 Atomic Routing:** Executes low-slippage swaps with dynamic priority fees and trailing profit-taking stops.
